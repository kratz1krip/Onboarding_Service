# ADR-001. Подход «шаблон и экземпляр» для модуля чек-листов

**Статус:** принято

## Контекст

У каждого отдела свой набор задач для новичков, и HR регулярно его меняет. Сначала чек-лист хранился одной таблицей со ссылками на общие задачи. Изменение шаблона сразу затрагивало тех, кто уже проходит онбординг, и у них пропадали отметки о выполненных задачах.

## Решение

Шаблоны чек-листов (`ChecklistTemplate`) хранятся отдельно. При назначении новичка для него создается собственная копия задач (`ChecklistTask`). Правки шаблона касаются только новых сотрудников, начатые чек-листы остаются как были.

## Рассмотренная альтернатива

Хранить версии шаблона и привязывать сотрудника к номеру версии. Экономит место, но усложняет запросы и отчеты и не позволяет добавить индивидуальную задачу одному новичку.

## Последствия

Объем таблицы задач растет с числом новичков, зато прогресс сотрудника не теряется при изменении шаблона.
